# FitTrack Phase 2

FastAPI backend for FitTrack Phase 1 + Phase 2 Modules 7-12.

## Run

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

Swagger: http://127.0.0.1:8000/docs

Phase 2 modules:
- Workout Plans & Scheduling
- Exercise Library
- Progress Comparison
- Streak Tracking
- Achievement Badges
- Personalized Dashboard
